## 📖 О проекте

**ctclient** — это консольный клиент Telegram, написанный на Python с использованием
[Telethon](https://github.com/LonamiWebs/Telethon) (работа с Telegram API) и
[Rich](https://github.com/Textualize/rich) (красивый цветной интерфейс в терминале).

Проект создан для тех, кто любит минимализм, работает в терминале и хочет оставаться
на связи, не переключаясь на графические приложения. Управление построено на цифрах
и коротких командах — всё интуитивно и быстро.

Название **ctclient** расшифровывается как **C**onsole **T**elegram **client** —
просто, понятно и отражает суть.

### ✨ Ключевые особенности

- 🔐 **Безопасная авторизация** — API ID/Hash запрашиваются один раз и сохраняются локально.
- 🎨 **Цветной интерфейс** — благодаря Rich всё выглядит живо и читаемо.
- 💬 **Список чатов с пагинацией** — по 6 чатов на страницу, команда `skip` листает дальше.
- 📁 **Поддержка папок** — переключение между папками через `f1`, `f2`, ...
- 📊 **Умная сортировка** — непрочитанные чаты всегда сверху (отключается в настройках).
- 👤 **Профили** — просмотр информации о пользователях и группах прямо из чата.
- 📷 **Отправка фото** — команда `send` с указанием пути к файлу.
- ⚙️ **Меню настроек** — кастомизация, поведение чатов и управление аккаунтом.
- 🗑️ **Удаление аккаунта** — с подтверждением по номеру телефона, кодом и задержкой 15 секунд.

## 🚀 Установка

### Требования

- Python **3.8** или выше
- Аккаунт Telegram
- API ID и API Hash (получаются на [my.telegram.org](https://my.telegram.org))

### Шаги

1. **Клонируйте репозиторий** (или просто скачайте файл `ctclient.py`):

   ```bash
   git clone https://github.com/yourname/ctclient.git
   cd ctclient

2. **Установите зависимости**

   ```bash
   pip install telethon rich

3. **Запустите клиент**

   ```bash
   python ctclient.py

## 🔑 Первый запуск

**При первом запуске ctclient попросит:**

    API ID и API Hash — возьмите их на my.telegram.org
    в разделе API Development Tools. Создайте приложение, если его ещё нет.

    Номер телефона — в международном формате, например +79001234567.

    Код подтверждения — придёт в Telegram (или SMS).

    Пароль 2FA — если у аккаунта включена двухфакторная аутентификация. 

**После успешного входа данные сохранятся в файлах:**
**Файл - Назначение**
**config.txt  - 	API ID и API Hash**
**ctclient.session  - 	Сессия Telegram (авторизация)**

    ⚠️ Не передавайте эти файлы третьим лицам! Они дают полный доступ к аккаунту.

### 🎮 Управление
Главное меню (список чатов)
Команда  -- 	Действие
1 … 6  -- 		Войти в чат с соответствующим номером
skip  -- 		Показать следующие 6 чатов
prev  -- 		Вернуться на предыдущую страницу
f1, f2, …  -- 		Переключиться на папку с указанным номером
f0  -- 		Показать все чаты (сбросить фильтр папки)
refresh  -- 		Обновить список чатов и папок
settings  -- 		Открыть меню настроек
exit  -- 		Выйти из клиента
